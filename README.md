# EDEN

太空舱文字冒险。你是被伊甸号买断余生时间的底层打工人，被投放到一个个"切片"世界里采集数据。切片各有自己的时间流速和相位循环（起始/繁荣/衰败），但游戏不会弹提示教你——数字的不对劲，要靠你自己撞见。

- 线上：<https://alnas1.github.io/Eden/>
- 编辑页：<https://alnas1.github.io/Eden/dev.html>（手机上也打开这个就能写章节；内容只存本机，导出 JSON 交给 AI 合并才算出版）

## 玩法现状

- **捏人**：开局登记苏醒档案——名字 + 一张身份卡（工蜂 / 摆渡人 / 白纸）。身份会解锁少量专属选项。
- **第一章**：舱内醒来，卖命合同，25 天余额。
- **第二章 · 第一切片「灰世界」**：后室氛围（潮湿地毯、无限走廊、坏灯管）。进入时的相位随机，起始/繁荣/衰败三条开场各带专属剧情和专属收藏品；主线是给手表型探测器完成 3 项采集，结算时"停留天数"和"扣减天数"对不上——这就是流速机制第一次自然露头。
- 页签：log / 地图 / 沙漏 / 背包 / 收藏。存档在浏览器 localStorage（键 `eden-save-v4`），换浏览器=新打工人。
